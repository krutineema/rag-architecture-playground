# RAG Architecture Playground

Hands-on experiments for learning Retrieval-Augmented Generation from an
AI-application-architecture perspective.

The repository deliberately starts without LangChain/LlamaIndex/LangGraph so
that the core pipeline remains visible.

## Progression

```text
01 Basic RAG
    ↓
02 Chunking
    ↓
03 Chunk overlap
    ↓
04 Top-k
    ↓
05 Metadata filtering
    ↓
06 Dense vs Sparse vs Hybrid
    ↓
07 Reranking
    ↓
08 Contextual Retrieval
    ↓
09 Retrieval Evaluation
    ↓
10 Generation Evaluation
    ↓
11 End-to-End Architecture Comparison
```

The key learning objective is not to collect RAG techniques. It is to understand
the failure modes and trade-offs that lead to each architectural choice.
